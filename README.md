# 番茄清单

一个个人待办 + 番茄钟网站，部署在 GitHub Pages 上，手机电脑实时同步。

**视图**：今天 / 明天 / 周计划 / 周日历 / 月日历 / 未安排 / 项目 / 统计。

**功能**
- 任务：分类（学习 / 工作 / 生活 / 运动）、多天任务、Markdown 笔记、预估番茄数、项目归类；没做完的自动延期到今天。
- 重复任务：每天 / 工作日 / 每周 / 每月，完成后自动排下一次。
- 日程：考试、面试、DDL、会议、课程，不用打勾；考试可以一键生成倒推复习计划。
- 一句话添加：「CS246 期中 周三下午3点」「每周三 交实验报告」「明天 写 A5 3个番茄」。
- 今天页：容量条、规划今天、预估建议、时间线（拖动排时间）、拖了好几天的任务提示、周回顾。
- 番茄钟：普通倒计时或自由计时；结束时弹窗、响铃、系统通知，一键开始休息或继续学习。
- 统计：番茄数、专注时长、分类占比、一天里最专注的时段、年度热力图。
- 导入课表（.ics）、导出备份、Ctrl+K 快速查找、可安装到桌面或手机主屏幕。

**账号与数据**
- 用邮箱和密码注册登录，数据保存在 Firebase，每个人只能读写自己的数据。
- 也可以用游客模式，数据只保存在当前浏览器。

**提醒的限制**：番茄结束和日程提醒，需要网页（或已安装的应用）保持打开。页面完全关闭后的后台推送需要 Firebase 的付费方案，目前没有启用。

部署步骤见 [部署说明.md](部署说明.md)。

Firestore 规则见 `firestore.rules`。数据结构：`users/{uid}` 存设置和项目，`users/{uid}/tasks`、`events`、`notes` 分别存任务、日程、笔记，所以规则必须覆盖 `users/{userId}` 下面的所有子集合。
